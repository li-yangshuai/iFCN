# Pi + iFCN 投稿基础现场审计

历史审计说明：本文记录本轮改进之前的版本，后续已接入三个后端并新增逻辑、器件端子检查。下文原来的“30 个执行完成”不等于通过新增条件，“只开放一个后端”也不再代表当前状态。最新实现、冻结输入和对照结果以 [本轮交付与证据](DELIVERY.md) 为准；历史结果未回写成新版成绩。

日期：2026-09-05。范围：WSL Ubuntu 24.04 下当前 iFCN 与 Pi 接入版本。本文区分现场重跑、历史记录和建议实验；不将其中任何一种替代另一种。

## 判断

目前已有足够具体的工程与实验基础，值得以“小规模组合 MolFCN/QCA 电路的 LLM 设计智能体”为主题准备应用型期刊稿件。TOY/MAJ 是合理的限定范围，没有必要仅为投稿扩大到工业规模。是否录用仍取决于新稿相对原 iFCN 的新增贡献、对照结果和表达准确性。

若目标是 Inderscience 的 International Journal of Computer Applications in Technology，其官方范围包含工程计算应用、CAD/CAE、知识系统及建模仿真，与该系统主题相符。这里没有核定年度分区，也不据分区推算录用概率。

## 本次实际运行

### 当前 Pi 后端批处理

- 冻结清单：TOY 顶层 17 个、MAJ 顶层 13 个 Verilog，共 30 个文件，逐个记录输入 SHA-256 和独立运行目录。
- 配置：固定 normal Graphviz/sifting 四相 2DDWave，seed=1，单命令 60 秒上限，3 路并发，运行到 simulate。
- 结果：28/30 完成 parse → pnr → map → simulate；TOY 为 17/17，MAJ 为 11/13。
- MAJ/RCA2 与 MAJ/mux41 在 pnr 达到 60 秒上限。它们不是所有原生算法均失败的证据。
- 完成案例：现有布线与时钟模板检查通过；面积 12–589 tiles，映射 79–2153 个元胞；Bistable 每输出 512 个样本，baseline/accelerated 最大绝对差异均为 0。
- 这项批处理没有调用 LLM、没有计算能耗，也没有把物理波形与输入 Verilog 真值表比较。不能称为 28 个电路的完整物理功能验证。
- 原始证据：`output/pi-validation/coverage-20260905T095332Z/results.json` 和 `results.csv`。
- 复现入口：`integrations/pi/validate_benchmarks.py`，支持 `--timeout`、`--workers` 和可重复的 `--case` 参数。

两个超时案例在单命令 180 秒上限、2 路并发下复查，均完成到 simulate：

| 输入 | 全流程墙钟时间 | 布局面积 | 元胞数 |
|---|---:|---:|---:|
| MAJ/RCA2 | 100.545 秒 | 775 tiles | 3256 |
| MAJ/mux41 | 144.498 秒 | 1736 tiles | 5077 |

因此 30 个输入均有本次实际完成到 simulate 的记录，但不能将事后重试写成统一 60 秒预算下 30/30 成功。两例原始复查结果保存在 `output/pi-validation/coverage-20260905T095912Z/results.json` 和 `results.csv`，两例数值引擎最大差异仍为 0。MAJ/mux41 报告 `max_iteration_samples=3`，应保留这一达到迭代上限的诊断；引擎间一致不证明求解已收敛。

### 其他原生算法

| 算法 | 输入 | 现场结果 |
|---|---|---|
| Compact Graph | TOY/xor2 | 6 节点、7 路由，4×10=40 tiles |
| Compact Graph 自适应扩张 | MAJ/1bitAdderMaj | 9 节点、11 路由，6×7=42 tiles |
| June 随机时钟 Graphviz | MAJ/1bitAdderMaj | 12 节点、14 路由，8×12=96 tiles |

三例均实际执行成功。两个 Compact 案例另检查节点和边覆盖、重叠、端点、简单四连通路径及相位约束，未发现错误；没有覆盖所有交叉约束。June 原生检查覆盖路由、相位、源感知交叉及映射交叉。使用 Debug 可执行文件，验证不依赖被优化掉的 assert。几何/相位检查不是布尔或器件物理功能证明。

原始证据：`output/pi-validation/native-algorithm-check/summary.json`，同目录保留复制输入、日志及布局快照。

### 真实 LLM

通过 Pi SDK 真实会话使用本机已配置默认模型 qwen3-vl-plus；系统提示来自 ifcn agent，仅开放四个 ifcn 工具。两次均为同一 XOR 的独立交互测试，无人工代填工具参数。

| 任务 | 时间 | 实际结果 |
|---|---:|---|
| 中文映射请求 | 37.464 秒 | 自主检查能力、提交、等待，完成 parse→pnr→map |
| 明确要求读取布局与 DAG | 54.803 秒 | 5 次工具调用，覆盖四工具，并读取两份 JSON |

两次都得到 3×4 tiles、79 元胞。每次 12 个清单产物存在且 SHA-256 匹配，独立检查 QCA 文本均有 79 个元胞块。这支持真实 LLM 能使用 Pi+iFCN 交付器件映射；两个相同 XOR 试验不能估计泛化成功率，也未验证 LLM 自主完成仿真和能耗。

第二次报告有来源表述缺口：模型没有读取 QCA，却称元胞数与该文件内容一致；还把非形式化 XOR 推断列入“已验证”。数值本身由外部检查证实，但最终报告的依据表述仍需约束和评测。

证据：`output/pi-validation/llm-validation-review.md`、同名 JSON 及报告引用的两个原始轨迹目录；复现入口 `integrations/pi/validate_llm.mjs`。

## 多算法与历史材料

源码中存在遗传启发式、Compact Graph、固定 2DDWave、逐电路 GCN+PPO 随机时钟以及带记忆的通用策略入口。当前 Pi 接入只开放固定 2DDWave 后端，尚不能宣称 LLM 已能选择全部算法。

- 随机时钟 27/27 历史汇总存在，但由旧结果复核和失败案例修复拼成，不是本次统一预算重跑，也不是 LLM 成功率。
- 36 个现成 QCA 版图的历史仿真器对照记录完整，两模型的 baseline/accelerated 差异为 0。这是数值实现一致性的证据，不自动证明源 RTL 的器件功能。
- `paper/data/experiment_results_README.md` 明确说明旧端口合法性检查漏掉共享输入侧，旧 CSV、Table 1、c17 的 72→48 等结果必须重新生成；这些旧比较值不能直接作为新稿性能结论。
- 已有能耗报告保留较大的积分误差，尚未完成步长与稳态收敛。可以描述分析功能集成，功耗优势需另行验证。

## 基准整理

`output/pi-validation/benchmark-audit.json` 与对应脚本对全部 30 个源文件做静态/真值表审计：字节去重 29 个，按输入输出声明顺序分类得到 16 个真值表类别。类别计数不做端口置换归并，不能称为绝对独立函数数。

TOY/MAJ 的同名文件可作为不同逻辑分解的实验对；12 对中 11 对等价。RCA2 两版本在 32 种输入中有 8 种输出不同，穷举输入输出端口置换仍不能等价。TOY/RCA2 与通常两位加法规范也有差异，应核对来源或明确把它作为无特定算术规范的组合网络。TOY/par_check 与通常全输入 XOR 定义不同，规范未提供，不能只凭文件名判错。TOY/xor2 模块头与声明端口不一致，当前前端按声明归一化并记录警告。

原始输入本次未修改。正式实验应冻结已确认的规范与文件版本，并保留更正记录。

## 新稿最值得补的实验

1. 明确新贡献：将现有 iFCN 后端组织为有状态、可恢复、产物可追溯的领域智能体；若主张多算法决策，先实际接入选择和回退，再测决策效果。原有算法作为已发表或已有的研究基础，正确引用。
2. 仍用 TOY/MAJ，比较固定脚本、同模型的通用 Pi 和领域主智能体。冻结任务、工具权限、预算与成功条件，记录交付正确性、人工干预、时间、token、失败恢复，以及报告是否有产物依据。先做覆盖主要功能和表示方式的代表任务，不把任意样本数量当期刊硬门槛。
3. 对论文准备展示的电路核对源逻辑与器件输出关系；若功耗只是可调用的分析功能，明确该范围。若声称数值准确或功耗改善，则补步长、稳态、能量平衡及公平对照。

没有必要为了这篇应用论文再训练一个新 LLM、增加多智能体或强行支持时序和工业规模电路。应把已实现的领域集成机制与可复核的结果讲清楚。
