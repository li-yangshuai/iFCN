# Random-clock Compact Graph Draw — iFCN native figure assets

Every circuit drawing in this directory is generated by iFCN itself. No
abstract replacement drawing is used. Prefixes `01`--`16` preserve the earlier
`1bitAdderMaj` study; prefixes `21`--`29` form the current crossing-demo figure.

Each SVG or LaTeX source has a same-name PDF. Assets `11`–`13` isolate the
core phase-assignment transition while keeping geometry and routes fixed.
Asset `01` is the only circuit image used in the main figure with the colored
2DDWave layered-graph convention. The placement and routing examples use
assets `11` and `12`, preserving the original iFCN TeX node and route colors.
The clock-legal result uses asset `08`, compiled from the final production
gate-level TeX with its original gray phase palette and per-cell phase
indices. Assets `14` and `15` remain auxiliary 2DD-style exports and are not
embedded in the main figure. Asset `16` is emitted at the
`routing_failed` stage before the caller rejects the candidate; it is paired
with the legal `X/88, Y/88` result in the archived adder study. Assets
`21`--`29` are the current A--D figure set for
`paper_2ddwave_crossing_demo.v`; asset `23` is emitted at a natural
`routing_conflict` during the default routing-order search.

Graphviz's upward Y axis is converted to iFCN's top-left coordinate convention
when placement coordinates enter the algorithm. No rotation or reflection is
performed after routing or phase assignment. The LaTeX writer only adapts
iFCN coordinates to TikZ's drawing axis.

Intermediate LaTeX snapshots are emitted by
`CircuitGraph::printLaTex(outputPath)`. Set `IFCN_PAPER_STAGE_DIR` to enable
them.

Reproduce the current natural conflict and recovery snapshots:

```bash
IFCN_PAPER_STAGE_DIR=/tmp/ifcn_cross_compact \
IFCN_TEST_VERBOSE=1 \
./build/stochastic_compact_graph_tests \
  tests/benchmarks_f/TOY/paper_2ddwave_crossing_demo.v
```

Reproduce the production Compact Graph result non-interactively:

```bash
QT_QPA_PLATFORM=offscreen \
IFCN_AUTO_GRAPH_RENDER_FILE=/path/to/1bitAdderMaj.v \
./build/fcnx_gui
```

Re-export the native cell-level and 3D assets from an IFCN file:

```bash
QT_QPA_PLATFORM=offscreen \
IFCN_AUTO_MAP_FILE=/path/to/layout.ifcn \
IFCN_AUTO_EXPORT_CELL_LAYOUT=/path/to/cell_layout.svg \
IFCN_AUTO_EXPORT_3D_LAYOUT=/path/to/clock_encoded_3d.svg \
./build/fcnx_gui
```
