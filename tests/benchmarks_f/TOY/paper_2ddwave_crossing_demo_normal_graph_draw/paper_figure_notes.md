# Native 2DDWave crossing-demo figure notes

## Circuit

The circuit implements the carry/majority function using only AND/OR gates:

\[
carry=(a\land b)\lor(b\land c)\lor(a\land c).
\]

The parsed graph has 8 nodes and 10 edges.

## Node labels

- `0`: input `a`
- `1`: input `b`
- `2`: input `c`
- `4`: `a AND b`
- `5`: `b AND c`
- `6`: `a AND c`
- `7`: `(a AND b) OR (b AND c)`
- `3`: output `carry`

## Native crossing optimization

- Raw fixed-layer order: 3 adjacent-layer crossings.
- OGDF optimized order: 2 adjacent-layer crossings.
- The optimized order swaps nodes `5` and `6`; the two remaining crossings
  are unavoidable for the three pairwise-product nodes under fixed layers.

The files `paper_2ddwave_crossing_demo_raw.svg`,
`paper_2ddwave_crossing_demo.svg`, and
`paper_2ddwave_crossing_demo_physical.svg` are generated by the project's
native `show_circuit_figure()` path.

## Six layout stages

1. Initial placement.
2. Placement after port reservation.
3. Initial routing with six failed edges.
4. Conflict-repair expansion.
5. Completed routing.
6. Final layout after one compaction pass (two accepted cuts).
